# 大懒猫创作平台

提供 Windows、Linux deb / AppImage 和 macOS 版本。请在发布列表中选择对应平台的安装文件。

[GitHub 主站发布列表](https://github.com/biglazycat-writer/biglazycat-release/releases) · [Gitee 备用发布列表](https://gitee.com/biglazycatwriter/blc-release/releases)

安装后可在「设置 → 关于」或托盘菜单中检查更新。GitHub 不可用时自动切换至 Gitee。Linux deb 版安装更新时会请求系统管理员授权。
